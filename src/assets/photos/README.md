# Photos

Drop a photo in this folder using one of the names below and it replaces the
placeholder on the next build. Any of .jpg, .jpeg, .png or .webp works. Photos
are resized and compressed automatically, so use the original files (ideally
2500 px or more on the long side for the wide ones).

The design relies on photos with a consistent warm, soft look. Edit them with
the same filter or preset before adding them.

## The one that matters most

| File name | Where it appears | Best shape |
|---|---|---|
| hero | Home page, filling the whole first screen, with your names over the lower half | Landscape, 3:2 or wider. Keep faces in the upper half and the bottom third calm, because text sits there. On phones the sides are cropped, so keep the subject near the centre. |

`hero` is also used as the top band of every other page until you add that
page's own photo, so adding this single file fills eleven placeholders.

## Top band of each page (optional, wide)
